### ST-001

- 标题：注册→登录→申请博主→创建文章→发布→浏览 全链路（端到端）
- 优先级：高
- 关联需求/设计：REQ-007, REQ-008, REQ-009, REQ-011, REQ-012, REQ-017 / SD-001, SD-002, SD-003
- 关联 BDD feature：—（S-bdd 阶段产出后回填）
- 测试场景：一条真实用户旅程：读者注册→登录获取 JWT→申请博主→创建草稿→发布→以读者身份浏览到该文章；验证跨 SD-001/002/003 数据流与权限边界（TC-DES-007 端到端）。

**前置条件**
- 认证状态：无需认证 → 依次获得注册用户 JWT → 博主 JWT
- 数据依赖：无（新建数据；预置测试密钥 `JWT_SECRET=test-*`，CON-003）
- 接口路径：POST /api/auth/register → POST /api/auth/login → POST /api/users/me/blogger → POST /api/articles → POST /api/articles/:id/publish → GET /api/articles?page=1

**测试步骤**

| 步骤 | 操作 | 输入 | 预期输出 |
|---|---|---|---|
| 1 | 注册读者 | `{username:"reader_e2e", email:"e2e@example.com", password:"Passw0rd!x"}` | 201 + 用户对象（无密码字段） |
| 2 | 登录 | `{email:"e2e@example.com", password:"Passw0rd!x"}` | 200 + JWT（exp−iat ≤ 24h） |
| 3 | 申请博主 | 携带 JWT：POST /api/users/me/blogger | 200 + 角色=blogger |
| 4 | 创建文章 | 携带 JWT：`{title, body, summary, tags:[], category}` | 201 + status=draft |
| 5 | 发布文章 | 携带 JWT：POST /api/articles/:id/publish | 200 + status=published |
| 6 | 读者视角浏览 | GET /api/articles?page=1 | 200 + 列表含该文章（published 可见） |

**预期结果**
全链路 6 步均成功；文章对读者可见；全程错误响应结构为 `{ error: { code, message } }`（CON-002）。

## 性能度量环境声明

> 阶段 7 执行本设计的性能基线用例（ST-029~031）时的度量环境声明（对应需求规格 NFR-001 testThreshold 的"测试环境类型确认"项）。
