## 1. 系统测试策略

### 1.1 测试目标
验证 17 个 SD 子系统的端到端业务链路、跨模块协作、安全约束、性能基线与异常路径，确认系统设计满足 25 需求（17 REQ + 5 NFR + 3 CON）。

### 1.2 测试范围与分层
| 层次 | 用例区间 | 数量 | 覆盖目标 |
|---|---|---|---|
| 单 SD 端到端 | TC-SYS-001~017 | 17 | 每个 SD 子系统主链路 |
| 跨模块协作 | TC-SYS-018~034 | 17 | SD 间 depends-on/collaborates-with |
| 性能基线 | TC-SYS-035~044 | 10 | NFR-001 性能指标 |
| 安全基线 | TC-SYS-045~054 | 10 | NFR-003 安全约束 |
| 异常与边界 | TC-SYS-055~064 | 10 | 状态机/配额/边界值 |
| **合计** | TC-SYS-001~064 | **64** | 17 SD + 5 NFR + 3 CON |

### 1.3 性能基线（NFR-001）
- 接口响应 P95 ≤ 200ms
- 单实例并发 ≥ 100 QPS 持续 10min
- 搜索响应 P95 ≤ 500ms
- 文件上传 P95 ≤ 1s（10MB 以内）
- WebSocket 推送延迟 ≤ 100ms
- 错误率 ≤ 0.1%（NFR-002）

### 1.4 安全基线（NFR-003）
- JWT 伪造/过期/封禁 token 拒绝
- RBAC 四级越权防护
- zod 输入校验全覆盖
- 原型链污染防护
- 文件上传魔数/MIME/大小/文件名消毒
