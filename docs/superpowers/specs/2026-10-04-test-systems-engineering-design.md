## 0. 问题定义（现状对照结论）

- **已有骨架**：W 模型左右 V（阶段 1↔验收测试设计 / 2↔系统测试设计 / 3↔集成测试设计 / 4↔单元测试设计，硬约束 #1 前置）；四级测试（单元/集成/系统/验收，check-artifact-gate 全 passed 门禁）；BDD 行为测试（L1-L4 features）；覆盖率 ≥80% + check-coverage-scope；边界条件探测（quality-standards 整洁标准一句）。

## 3. 冒烟准入机制（D3）

- **时序**：阶段 6/7/8 开跑完整测试套件前，先执行该阶段冒烟子集（test-case 标记列筛出）；冒烟子集存在失败 → 不开跑完整套件，走普通 V/G 失败链（hard-constraints）；冒烟全过 → 开跑完整套件。结果一律经 `/wm test result=` 真实回填，机制不新增命令、不新增脚本。
- **标记面**：`templates/test-case.md` 用例表加「冒烟」标记列（✓/空）；存量模板使用面实查（test-case.md 为项目侧模板——实现时实查 check-artifact-gate 等是否解析其结构，预期零消费点，如有消费点则硬切）。
- **细则落点**：phase-6-integration-test.md / phase-7-system-test.md / phase-8-acceptance-test.md 各加「冒烟准入」节（同一形态：时序 + 失败链 + 标记列指引 + 「零新脚本」知情声明）。
